The Problem

Gelbe Seiten does not have a data problem once.

It has a data decay problem every day.

Businesses update their websites, not the directory. Opening hours change. Services disappear. Locations move. Listings slowly become less reliable.

At 3.8M businesses, manual updates do not scale.

And AI on every record is not intelligence. It is a bill.

So the real problem is:

How do we keep directory data fresh, trustworthy, and continuously updated — without spending heavily on every check?

Our 3 Main Innovations

What makes this system different.

The Self-Learning Brain

Every LLM call trains a free regex pattern. The pipeline gets cheaper with every single run.

Adaptive Monitoring

Check frequency adjusts automatically. Active sites checked more. Stable sites less. Dead sites backed off. 80% of crawls skipped.

Footer Hash Check

We hash only the footer — where business data lives. Blog changes never trigger false extractions.
